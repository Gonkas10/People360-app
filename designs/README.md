# Artes vetoriais do Clube Futebol Santa Iria

Este diretório guarda versões vetoriais dos dois faixas solicitadas:

- `santa-iria-banner-1.svg` — faixa azul com hashtag #SouSantaIria e lema central.
- `santa-iria-banner-2.svg` — faixa branca com bordas azul/amarelo e frase institucional.
- `santa-iria-banner-1.pdf` e `santa-iria-banner-2.pdf` — exportações vetoriais em PDF prontos para impressão/maquete digital.

## Como gerar outros formatos (AI, EPS, CDR)

1. Abra o ficheiro `.svg` ou `.pdf` numa ferramenta vetorial (Illustrator, Inkscape, CorelDraw ou Figma).
2. Verifique se as fontes sugeridas (Montserrat/Arial) estão instaladas; caso contrário, substitua por equivalentes sans-serif.
3. Exporte no formato desejado:
   - **Illustrator (.ai)**: `File → Save As → Adobe Illustrator (*.ai)`.
   - **EPS (.eps)**: `File → Save As → EPS (*.eps)` ou `File → Export → EPS`.
   - **CorelDRAW (.cdr)**: `File → Save As → CorelDRAW (*.cdr)` ou importe o SVG/PDF e grave no formato nativo.

As formas do escudo e das barras são 100% vetoriais, permitindo redimensionamento sem perda de qualidade.
